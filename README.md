# 給食アレルギーチェッカー

学校給食の献立ファイルから、選択したアレルゲンを含む可能性のある献立を確認する、依存関係なしのブラウザアプリです。

## 使い方

`index.html` をブラウザで開き、CSV・TSV・PDFファイルを選択するか、献立データを貼り付けてください。PDFは文字情報を含むPDFに対応しています。1行目は「日付」「献立名」「原材料」などの見出しとして認識されます。献立を読み込んでアレルゲンを選択した後、「アレルギーチェックを開始」を押すと、「日にち」「メニュー」「判定」の3列で、日付と曜日ごとに整理された結果が表示されます。

チェック後は「盛り付け表をCSV保存」から全献立の表を出力できます。アレルギーの可能性がある献立の「盛り付け」列には「✕」が入り、該当しない献立は空欄になります。

「盛り付け表を画像表示」では、同じ判定結果を画像の表として表示します。可能性のある料理には赤い「✕」が付き、表示後にPNGとして保存できます。

PDFを読み込んだ場合は、抽出した表ではなく読み込んだPDFの1枚目の画像を使用し、アレルギーの可能性がある行の右側に赤い「✕」を重ねて表示します。判定自体はPDF全体を対象にします。

PDFの読み込みにはPDF.jsを使用しています。スキャン画像だけのPDFは文字を抽出できないため、現在は対象外です。判定は文字列による確認補助です。実際の喫食可否は、学校や栄養教諭の指示、食品の正式なアレルギー表示を確認してください。
