# 給食アレルギーチェッカー

学校給食の献立ファイルから、選択したアレルゲンを含む可能性のある献立を確認する、依存関係なしのブラウザアプリです。

## 使い方

「材料表」には、アレルギー判定に使うCSV・TSV・PDFを読み込むか、献立データを貼り付けます。「盛り付け表」には画像表示に使うPDFを別に読み込みます。1行目は「日付」「献立名」「原材料」などの見出しとして認識されます。材料表を読み込んでアレルゲンを選択した後、「アレルギーチェックを開始」を押すと、アレルギーの可能性がある料理だけが、日にちの行の次にメニューの行が続く形式で表示されます。
日付の見出しがない材料表でも、`2026/09/14`、`2026年9月14日`、`8/28`、`8月28日` などの日付形式を検出して「日にち」に表示します。

チェック後は「盛り付け表をCSV保存」から全献立の表を出力できます。アレルギーの可能性がある献立の「盛り付け」列には「✕」が入り、該当しない献立は空欄になります。

「盛り付け表を画像表示」では、同じ判定結果を画像の表として表示します。可能性のある料理には赤い「✕」が付き、表示後にPNGとして保存できます。

「盛り付け表を画像表示」を押すと、別に読み込んだ盛り付け表PDFの1枚目の画像を使用し、アレルギーの可能性がある行の右側に赤い「✕」を重ねて表示します。判定自体は材料表を対象にします。

PDFの読み込みにはPDF.jsを使用しています。スキャン画像だけのPDFは文字を抽出できないため、現在は対象外です。判定は文字列による確認補助です。実際の喫食可否は、学校や栄養教諭の指示、食品の正式なアレルギー表示を確認してください。
